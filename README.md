CyberShield — Cybercrime & Cybersecurity Awareness

About the Project:
CyberShield is a website dedicated to raising awareness about cybercrime, cybersecurity, and online safety. It provides information about common cyber threats, different types of cybercrime, and the importance of protecting personal information in the digital world.

This project was developed to explore front-end web development while presenting cybersecurity information through a clean and visually engaging user interface.

Features:

Cybercrime Awareness: Information about common types of cybercrime.
Cyber Threats: An introduction to online threats and their examples.
Cybersecurity Education: Highlights the importance of digital safety and secure online practices.
Custom User Interface: A visually styled layout featuring cards, buttons, and navigation.
Informative Content: Educational material designed to help users better understand online security.

Technologies Used:

CSS3
Google Fonts — Roboto
